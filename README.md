# Amazon Clone

A clean, beginner-friendly Amazon clone navbar and footer built using **Django**, **HTML**, and **Pure CSS**.

## Features
- Amazon-style header with logo, location selector, search bar, language selector, account menu, returns/orders, and shopping cart.
- Responsive secondary navigation bar.
- Large content space.
- 4-column simplified footer with "Back to top" button and footer bottom bar.

## How to Run
1. Make sure Python and Django are installed:
   ```bash
   pip install django
   ```
2. Run the development server:
   ```bash
   python manage.py runserver
   ```
3. Open `http://127.0.0.1:8000/` in your browser.
